## 项目经历

**2026.07 - 2026.09  个人深度研究助手(agent\_research)**

⚫ **技术栈**:Python、LangGraph、Gradio、FastAPI、SQLite、Qdrant、MCP 协议

⚫ **项目介绍**:面向个人开发者的深度研究智能助手,输入研究主题即可自动完成「路径规划→文献检索→知识整理→报告生成→沉淀入库」全流程,面向学术研究、技术调研、文献综述等场景，持续构建个人知识库。

⚫ **多 Agent 编排 + MCP 工具接入**:设计 Planner/Collector/Engineer/Writer 四角色 Agent,基于 LangGraph StateGraph 驱动状态机流转,线程安全共享黑板实现跨 Agent 数据传递;通过 4 个 MCP Server 标准化协议接入 11 个工具(arXiv/OpenAlex/CrossRef/PDF解析/Obsidian同步等),新工具即插即用。

⚫ **四层记忆体系**:短期/工作/长期/偏好四层架构,长期记忆采用向量60%+关键词20%+图谱20% 三路混合召回 + 权重融合;JEV 质量评分+ 语义去重保障知识库质量。

⚫ **JEV 独立判别 + 全链路质量保障**:生成用 DeepSeek-V3,判断用本地 OpenJev(Qwen3.5-0.8B NLI 交叉编码器),两套模型完全独立避免「LLM 自评」问题。
