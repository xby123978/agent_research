## 项目经历

**2026.07 - 2026.09  个人深度研究助手(agent\_research)**

⚫ **技术栈**:Python、LangGraph、DeepSeek-V3 API、Gradio、FastAPI、SQLite、Qdrant、Ollama、MCP 协议

⚫ **项目介绍**:面向个人开发者的深度研究智能助手,输入研究主题即可自动完成「路径规划→文献检索→知识整理→报告生成→沉淀入库」全流程,持续构建个人知识库。系统采用七层分层架构,核心包含多 Agent 协作编排、四层记忆体系、JEV 独立判别决策、MCP 标准化工具接入四大模块,支持 Gradio 网页界面与 REST API 双入口,面向学术研究、技术调研、文献综述等场景,为单机部署提供完整的工程化落地。

⚫ **多 Agent 编排 + MCP 工具接入**:采用主管-工人模式,设计 Planner/Collector/Engineer/Writer 四角色 Agent,基于 LangGraph StateGraph 驱动状态机流转,线程安全共享黑板实现跨 Agent 数据传递,异常自动升级重规划(最多 2 轮);通过 4 个 MCP Server 标准化协议接入 11 个工具(arXiv/OpenAlex/CrossRef/PDF解析/Obsidian同步等),新工具即插即用。

⚫ **四层记忆体系**:短期/工作/长期/偏好四层架构,长期记忆采用向量60%+关键词20%+图谱20% 三路混合召回 + 权重融合;JEV 质量评分(<0.3 拒绝)+ 语义去重(>0.92 跳过)保障知识库质量。

⚫ **JEV 独立判别 + 全链路质量保障**:生成用 DeepSeek-V3,判断用本地 OpenJev(Qwen3.5-0.8B NLI 交叉编码器),两套模型完全独立避免「LLM 自评」问题;0 token 生成,confidence 分三档(≥0.8 自动 / 0.5-0.8 复核 / <0.5 丢弃);每阶段硬门限,事实校验核心结论需 ≥2 篇独立文献支持,JEV 一致性 <0.9 触发重写防控幻觉。

⚫ **端到端验收**:10 个标准任务(Transformer综述/RAG技术/知识图谱构建等)成功率 ≥90%,真实环境单任务端到端实测约 3.5 分钟(含 4 次 DeepSeek 调用 + 文献检索 + 知识抽取 + 报告生成全链路)。
